Interactive REST API documentation and live endpoint runner for Project P_013. Evaluators can test each API call with zero setup directly against the live backend.

Back to Main App

1. System Health & Compliance

GET /api/health
Project metadata, P_013 verification and backend server status

2. Authentication & Authorization (JWT + Bcrypt)

POST /api/auth/login
Authenticate patient or doctor, returns JWT token & user session
Request Body (JSON)
GET /api/auth/me
Fetch currently authenticated user profile
PUT /api/auth/profile
Update user profile (phone, address, blood group, age)
Request Body (JSON)

3. Clinical Specialty Departments & Doctor Discovery

GET /api/doctors?dept=Cardiology
Filter credentialed senior specialists strictly by clinical specialty
GET /api/doctors/doc-in-101
Get detailed profile, license & clinic information for single doctor

4. Virtual Consultations & Real-Time Slot Locking

GET /api/appointments/slots
Real-time slot availability for doctor on specified date
GET /api/appointments/my
Fetch patient appointments or doctor OPD consultation queue
PUT /api/appointments/:id
Reschedule or update consultation details (slot, date, symptoms, clinical notes)
Request Body (JSON)

5. Electronic Health Records & Lab Reports (EHR)

GET /api/records/my
Fetch patient diagnostic reports, pathology blood tests & radiology scans

6. Billing & Razorpay Signature Verification

POST /api/payment/create-order
Create server-side Razorpay order with calculation of platform fee
Request Body (JSON)
POST /api/payment/verify
Verify cryptographic HMAC-SHA256 Razorpay payment signature
Request Body (JSON)

7. Agora RTC Video Conferencing Tokens

GET /api/video/token
Generate secure dynamic WebRTC video room tokens for doctor & patient

8. Digital Prescriptions & QR Verification

GET /api/prescriptions/:id
Fetch verified e-prescription record by QR code ID

9. Notifications & SMS Audit Log

GET /api/notifications
Audit trail of automated SMS and Email confirmation dispatches
